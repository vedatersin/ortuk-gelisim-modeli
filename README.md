# TYMM Örtük Gelişim Modeli

Türkiye Yüzyılı Maarif Modeli için e-Okul biçimli öğrenci gelişim izleme paneli.

## Kaynak Kapsamı

- `TYMM_Ortuk_Gelisim_Modeli_Proje_Analiz_Raporu.docx`: modül, mimari, e-Okul entegrasyonu, IRT/LGM/YEM, FIML ve dashboard gereksinimleri.
- `TYMM Örtük Gelişim Modeli.pptx`: teorik çerçeve, boylamsal ölçüm, intercept/slope, gelişim yörüngesi ve uygulama adımları.
- `MAP-Growth-NWEA_factSheet.pdf`: RIT, dönemsel büyüme izleme ve akran/norm karşılaştırması yaklaşımı.
- `tymm_ortuk_gelisim_yapay_veri.xlsx`: T0, T1, T2, T3 öğrenci ölçümleri ve dengesiz panel örnekleri.
- Görsel referanslar: e-Okul benzeri renk, form yoğunluğu, sol menü ve tablo düzeni.

## Ekranlar

- öğretmen filtreleri: ders, dönem, sınıf/şube ve öğrenci
- öğrenci bütüncül durum kartları
- T0-T3 boylamsal büyüme eğrisi
- öğrenme kanıtı zaman tüneli
- rubrik 1-4 veri girişi
- madde bankası / IRT alanları
- sınıf listesi ve dengesiz panel görünümü
- uygulama modülleri ve sistem bileşenleri

## Komutlar

```bash
npm install
npm run dev
npm test
```
